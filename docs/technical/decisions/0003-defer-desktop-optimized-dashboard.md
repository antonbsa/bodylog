# 0003 — Defer Desktop-optimized Dashboard

## Status

Accepted

## Context

The main V1 value is quick logging and simple weekly visualization. A full desktop analysis dashboard would add design and implementation scope.

## Decision

Desktop should work minimally, but desktop-friendly dashboards are deferred to future versions.

## Consequences

V1 UI work should not optimize for desktop-heavy analysis workflows. Future versions can revisit this once the mobile workflow is complete.
