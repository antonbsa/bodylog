# 0012 — Use Neutral Variation Interpretation

## Status

Accepted

## Context

Whether a metric increase or decrease is desirable depends on the user's current goal and context.

## Decision

In V1, show whether a metric went up, down, or stayed stable without classifying the change as good or bad.

## Consequences

The UI can show direction indicators, but it must avoid health, training, or diet recommendations in V1.
