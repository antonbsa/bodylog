# 0018 — Include Basic PWA in V1

## Status

Accepted

## Context

Installability improves mobile usage, but offline-first behavior would add synchronization complexity.

## Decision

Include basic PWA installability in V1, without full offline-first behavior.

## Consequences

V1 needs a manifest and icons. Offline storage and sync remain out of scope.
