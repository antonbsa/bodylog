# 0006 — Include CSV Import in V1

## Status

Accepted

## Context

Existing historical data is stored in a spreadsheet. Re-entering that data manually would make the app less useful at launch.

## Decision

Include CSV import in V1 as the last major feature.

## Consequences

The initial import can support the canonical CSV format first. Mapping alternate spreadsheet headers can be added later if needed.
